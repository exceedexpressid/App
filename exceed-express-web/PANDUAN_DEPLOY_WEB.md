# Portal Mitra Olshop — Exceed Express (Versi Web & PWA iOS / Android)

## Penting Saat Upload ke GitHub Pages (`exceedexpressid.github.io`)
Agar **Logo Aplikasi**, **Tampilan Background & Splash Screen**, dan tombol **Instal Aplikasi lewat Browser** berfungsi di Android & iOS, **unggah SELURUH isi folder `exceed-express-web/`** ke repository GitHub Anda (jangan hanya `index.html` saja):
- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `.nojekyll`, `404.html`, `favicon.ico`, `favicon.png`
- Folder `assets/` (`splash.jpg`, `bg-apk.jpg`, `logo-app.png`, `logo.svg`, `app-icon.svg`)
- Folder `icons/` (`apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, dll.)

## Cara Pasang Aplikasi di HP (Tanpa APK)
- **Android (Chrome):** Buka link web → ketuk **"Pasang di Layar Utama"** (atau menu **⋮ → Tambahkan ke layar utama → Instal**).
- **iPhone / iPad (iOS Safari):** Buka link web di **Safari** → ketuk ikon **Share (⬆️)** → **"Tambah ke Layar Utama"** → **"Tambah"**.
